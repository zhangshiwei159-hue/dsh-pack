# DSH Pack

把插件组合成能直接工作的 DeepSeek Harness 能力包。

> ⚠️ **非官方社区项目**，与 DeepSeek 官方无隶属或授权关系。

## 这是什么

DSH Pack 不是又一个插件列表，而是把插件、配置、环境检查和运行时组合成可以直接安装的「能力包」。

## 当前状态

- **V0.1**，免费测试版
- **Windows** 实测（DeepSeek Harness `v0.1.0-rc.6`）
- 当前第一个能力包：**浏览器增强包**（让 Harness 获得真实浏览器操作能力）

## 使用前请先安装 DeepSeek Harness

DSH Pack 是 DeepSeek Harness 的能力扩展，不包含 Harness 本体。

如果你的电脑还没有安装 DeepSeek Harness，请先前往官方项目：

https://github.com/deepseek-ai/deepseek-harness

官方当前快速启动方式：

```powershell
npx @deepseek-ai/dsh web
```

需要提前安装 Node.js。

确认 DeepSeek Harness 可以正常运行后，再继续安装 DSH Pack Runtime 和能力包。

> DeepSeek Harness 当前仍处于开发者预览阶段，安装方式可能随官方版本更新。请以官方仓库最新说明为准。
